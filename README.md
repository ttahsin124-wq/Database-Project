CRUD application built using Python, Tkinter, ttkbootstrap, and MySQL.
It allows administrators to manage Users and News Articles, including creating, updating, deleting, searching, and viewing relational data.
**🚀 Features   **                                                      
**👤 User Management**
1.Add, edit, delete users                                                       
2.Search users by name, user_id, or age
3.View complete user details
4.Double-click a user to see all news posted by that user
5.Auto-sorted and filterable table view
**📰 News Management**
1.Add, edit, delete news articles
2.Search news by title, news_id, or author name
3.Double-click to open article editor
4.Supports full article body text
5.Automatically stores date of creation 
**📁 General Features**
1.Modern UI using ttkbootstrap
2.MySQL database integration
3.Popup modals for editing and creating content
4.Sorting TreeView columns
5.Clean architecture separated into UI, backend, and database logic
